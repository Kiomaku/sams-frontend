# Contributing

Thanks for helping improve SamS! 🙌

1. Fork the repo and create a branch: `git checkout -b feat/my-change`
2. `cp .env.example .env`, then `npm install && npm start`
3. Keep PRs small and focused; run `npm run build` before pushing.
4. **Never commit `.env`** or any secrets. Open an issue first for big changes.

باز کردن Issue و Pull Request به هر دو زبان فارسی و انگلیسی خوش‌آمد است.
