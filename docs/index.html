Quick startشروع سریع

You need Node.js 18+ and a running backend.به Node.js نسخه‌ی ۱۸+ و یک بک‌اند در حال اجرا نیاز دارید.

Clone & installکلون و نصب

git clone https://github.com/kiomaku/sams-frontend.git
cd sams-frontend
npm install

Create your .envساخت فایل .env

Copy the template and edit it. It is git-ignored, never commit it.قالب را کپی و ویرایش کنید. در Git نادیده گرفته می‌شود؛ هرگز کامیتش نکنید.

cp .env.example .env

Start your backendبک‌اند را اجرا کنید

Run your Python API on port 5000 (or change API_PROXY_TARGET).API پایتون را روی پورت ۵۰۰۰ اجرا کنید (یا API_PROXY_TARGET را تغییر دهید).

Run the frontendاجرای فرانت‌اند

npm start

Openباز کنید: http://localhost:5173

Deployاستقرار

Build once, then pick how to serve dist/.یک‌بار بسازید، سپس روش سرو کردن dist/ را انتخاب کنید.

npm run build

Serve the build from your Python app, same origin, no CORS.بیلد را از همان اپ پایتون سرو کنید؛ هم‌مبدأ و بدون CORS.

app = Flask(__name__, static_folder="dist", static_url_path="")

@app.route("/")
def index():
    return app.send_static_file("index.html")

Reverse proxy; keep the timeout generous, replies can be slow.پروکسی معکوس؛ تایم‌اوت را بزرگ بگذارید، پاسخ‌ها ممکن است کند باشند.

server {
  listen 80;
  root /var/www/sams/dist;
  location /api/ {
    proxy_pass http://127.0.0.1:5000;
    proxy_read_timeout 180s;
  }
  location / { try_files $uri /index.html; }
}

Set VITE_API_BASE and enable CORS with credentials on the backend (and SameSite=None; Secure cookies on https).VITE_API_BASE را تنظیم کنید و در بک‌اند CORS با credentials را فعال کنید (روی https کوکی SameSite=None; Secure).

VITE_API_BASE=https://api.example.com

API guideراهنمای API

Session-cookie auth. Send cookies with every request. Full details inاحراز هویت با کوکی نشست. کوکی را با هر درخواست بفرستید. جزئیات کامل در API.md.

POST/api/auth/register

Create account: email + password (8+).ساخت حساب: ایمیل + رمز (حداقل ۸ نویسه).

POST/api/auth/login

Log in, sets the cookie.ورود و ست شدن کوکی.

POST/api/auth/logout

Clear the session.پاک کردن نشست.

GET/api/auth/me

Restore login on page load (401 = not logged in).بازیابی ورود هنگام بارگذاری (۴۰۱ = وارد نشده).

POST/api/chat 🔒

Send a message. No session_id = new chat. Returns Markdown.ارسال پیام. بدون session_id = چت جدید. خروجی Markdown است.

GET/api/sessions 🔒

List your chats.فهرست چت‌های شما.

GET/api/sessions/<id> 🔒

Full message history.تاریخچه‌ی کامل پیام‌ها.

DELETE/api/sessions/<id> 🔒

Delete one of your chats.حذف یکی از چت‌های شما.

GET/api/status

Workers, queue depth, history count (public, polled every 3s).ورکرها، عمق صف و تعداد تاریخچه (عمومی، هر ۳ ثانیه).

{ "message": "hi", "session_id": 3, "personality": "chill", "goals": "be helpful", "red_lines": "stay respectful", "history": true }

→ { "success": true, "response": "Hello!", "worker": 3, "session_id": 3 }

Troubleshootingرفع اشکال

The page looks unstyledصفحه بدون استایل دیده می‌شود

Tailwind is not scanning HeroUI. Stop the server, then:Tailwind کلاس‌های HeroUI را نمی‌خواند. سرور را متوقف کنید و:

rm -rf node_modules/.vite
npm install
npm start
Replies fail with 502 / 503پاسخ‌ها با خطای ۵۰۲ / ۵۰۳ شکست می‌خورند

503 queue_timeout: all workers are busy. 502 retries_exhausted: the worker failed. Behind a proxy, raise the read timeout.۵۰۳: همه‌ی ورکرها مشغول‌اند. ۵۰۲: ورکر پس از چند تلاش شکست خورد. پشت پروکسی، تایم‌اوت خواندن را بیشتر کنید.

Code shows as one plain lineکد به‌صورت یک خط ساده نمایش داده می‌شود

The API must return Markdown with ``` fences and real line breaks. The frontend can't rebuild lost newlines.API باید Markdown با فِنس ``` و خط‌های جدید واقعی برگرداند. فرانت‌اند نمی‌تواند خط‌های ازدست‌رفته را بازسازی کند.

I get logged out on reloadبا رفرش از حساب خارج می‌شوم

The session cookie isn't sent. Use the same origin (proxy) or enable CORS with credentials and proper SameSite cookies.کوکی نشست ارسال نمی‌شود. از همان دامنه (پروکسی) استفاده کنید یا CORS با credentials و کوکی SameSite مناسب را فعال کنید.

Emoji images don't loadتصاویر ایموجی بارگذاری نمی‌شوند

The CDN may be blocked. They fall back to your system emoji; or host the set yourself and change BASE.ممکن است CDN مسدود باشد. به ایموجی سیستم برمی‌گردند؛ یا مجموعه را خودتان میزبانی کنید و BASE را عوض کنید.
